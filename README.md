<h2 align="center">🚀 How It Works</h2>

<div align="center">

<table>
<tr>
<td align="center" width="33%"><h3>① Drop</h3>Candidates, stages, sources, recruiters, dates, CTC<br/><sub>.csv · .xlsx · .xls</sub></td><td align="center" width="33%"><h3>② Analyse</h3>Columns are detected and every metric is computed locally<br/><sub>Instant, even on big files</sub></td><td align="center" width="33%"><h3>③ Act</h3>Read the brief, fix the critical items first<br/><sub>Recommendations included</sub></td>
