# 🧠 HR Insight Analyzer

An offline "auto-analyst" for HR data — upload a dataset and get an instant, plain-English summary of what's happening, without writing a single formula.

**🔗 Live Demo:** https://project-dashboard-demo.netlify.app/hr-insight-analyzer

> 💻 **Best viewed on a laptop/desktop** — this dashboard is not optimized for mobile screens, so please use a computer for the best experience.

> This is a public demo running on sample data. Data export is disabled in this preview — get in touch below if you'd like to see the full working version.

---

## Overview

Before diving into a deep analysis, HR teams often just need a fast first read on a dataset — what's changed, what stands out, what needs a closer look. HR Insight Analyzer does exactly that: upload a spreadsheet and get an automatically generated brief summarizing the key patterns in your data, in plain language.

## Features

- **Rule-based analysis engine** — every insight is calculated directly from your data using statistics, nothing guessed or invented
- **Fully offline** — no data ever leaves your browser, making it safe to use with sensitive HR data
- **Auto-generated briefs** — instant summaries covering trends, outliers, and key numbers
- **One-click export** of the generated brief for sharing with stakeholders
- **Clean, distraction-free interface** designed for quick reads, not dashboards you have to learn

## Who It's For

- HR professionals who need a fast first read on attrition, headcount, or demographic data
- Managers preparing for a review meeting who don't have time to build a report
- Anyone who wants a quick, trustworthy summary of a dataset before deciding where to dig deeper

## Privacy

All analysis happens directly in your browser — nothing is uploaded to a server, so it's safe to use with real, sensitive workforce data.
